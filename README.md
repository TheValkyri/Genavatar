# 🎓 THPT Vĩnh Thuận - Trình Tạo Khung Ảnh Đại Diện (Avatar Frame Generator)

Ứng dụng web hiện đại giúp học sinh, giáo viên và cựu học sinh trường **THPT Vĩnh Thuận** dễ dàng tạo ảnh đại diện chào năm học mới 2026 - 2027 với các mẫu khung đồ họa sắc nét, chuẩn nhận diện truyền thống từ năm 1979.

---

## ✨ Tính Năng Nổi Bật

- **Khung Chính Thức 2026 - 2027:** Tích hợp sẵn logo trường, cổng trường ngói đỏ, học sinh áo dài trắng và dải băng *"Đoàn kết - Sáng tạo - Phát triển"*.
- **Kho Khung Đồ Họa Phong Phú:** 6 mẫu 2D tươi trẻ cho học sinh và 2 mẫu trang trọng cho kỷ niệm trường & thầy cô.
- **Tương Tác Trực Tiếp Trên Canvas:**
  - Hỗ trợ cảm ứng đa điểm trên mobile: Chụm 2 ngón để phóng to/thu nhỏ (*Pinch-to-zoom*), vuốt 1 ngón để di chuyển (*Touch Pan*).
  - Thao tác chuột và con lăn mượt mà trên desktop.
  - Xoay 90°, lật gương ảnh selfie, tinh chỉnh góc nghiêng và bộ lọc Độ sáng / Độ tương phản.
- **Kéo Thả Tự Do Logo Trường:** Chạm hoặc click trực tiếp vào logo trên canvas để di chuyển đến bất kỳ góc nào mong muốn.
- **Huy Hiệu Tên & Lớp Học Sinh:** Cho phép chèn nhãn Họ tên, Lớp học và Niên khóa trang trọng.
- **Xuất Ảnh Chuẩn HD & 2K:** Render Offscreen Canvas chuẩn 1080p và 2048x2048 không lo vỡ hạt khi đăng lên Facebook, Zalo.
- **100% Client-side:** Xử lý toàn bộ trên trình duyệt máy khách, không lưu trữ ảnh cá nhân lên server, bảo mật tuyệt đối.

---

## 🛠️ Công Nghệ Sử Dụng

- **Frontend:** [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler:** [Vite](https://vite.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Hiệu ứng & Canvas:** HTML5 2D Canvas API + Canvas Confetti
- **Deploy:** Vercel Ready

## 🚀 Hướng Dẫn Cài Đặt & Chạy Cục Bộ

```bash
# 1. Clone repository
git clone https://github.com/TheValkyri/Genavatar.git
cd Genavatar

# 2. Cài đặt các gói phụ thuộc
npm install

# 3. Khởi chạy dev server
npm run dev

# 4. Build sản phẩm production
npm run build
```
